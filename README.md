# ピアノ練習(Piano Practice)

MIDI キーボードをブラウザに接続し、手持ちの MusicXML 譜面を「正しい鍵盤を押すまで待ってくれる練習モード」で練習できる、完全無料のピアノ練習 Web アプリです。

**公開 URL**: https://t-yamaguchi0819.github.io/pianoPractice/

## 特徴

- **弾いて進める練習モード** — 期待される鍵盤(青表示)を押すまでカーソルが待機。和音は一音ずつゆっくり押しても OK(押した音は緑=充足済みのまま維持)。誤打(赤表示)はカウントされますが進行はブロックしません
- **パート練習** — 右手のみ / 左手のみ / 両手を切り替え
- **小節範囲ループ** — 開始・終了小節を指定すると、その範囲を自動で繰り返し練習
- **譜面はユーザー持ち込み** — `.xml` / `.musicxml` / `.mxl`(圧縮 MusicXML)をドラッグ&ドロップで読み込み。MuseScore などから書き出したファイルが使えます
- **練習記録** — 曲ごとの練習回数・累計時間・完走回数をブラウザの localStorage に保存(サーバーには何も送信しません)
- **完全クライアントサイド** — サーバー・アカウント・データベースなし。静的ホスティングのみで動作

## 使い方

1. MIDI 対応の電子ピアノ / キーボードを USB でパソコンに接続する
2. **Chrome / Edge / Firefox** で公開 URL を開く(Safari は Web MIDI API 非対応のため利用できません)
3. ブラウザが MIDI アクセスの許可を求めたら「許可」する
4. 譜面ファイルを開く(またはサンプル曲を選ぶ)
5. 「練習を開始」を押し、青く光る鍵を弾く

MIDI キーボードがなくても、画面下部の鍵盤をクリックして動作を試せます。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # ユニットテスト(Vitest)
npm run build      # 本番ビルド(dist/)
npm run lint       # ESLint
npm run format     # Prettier
```

- **技術スタック**: Vite + React 18 + TypeScript + Tailwind CSS、譜面表示は [OpenSheetMusicDisplay](https://opensheetmusicdisplay.org/)、MIDI 入力は Web MIDI API を直接使用
- **構成**: `src/core/` は React に依存しない純粋ロジック(MIDI 解析・期待ノート抽出・練習ステートマシン・記録)で、ユニットテストの対象。`src/components/` が UI
- **デプロイ**: `main` ブランチへの push で GitHub Actions がテスト → ビルド → GitHub Pages へ自動デプロイ

## ライセンス・方針

- 著作権のある楽曲は同梱・配信しません。譜面はユーザーが自分のファイルを読み込む方式です
- 練習記録・設定はすべてブラウザ内(localStorage)に保存され、外部送信されません
